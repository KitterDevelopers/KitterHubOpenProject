# 第二篇 · 社区发言守则

> 本篇是《KitterHub 社区管理规定》第二篇；规则总入口见站内「规则中心」。

KitterHub 是面向创作者的社区。为维护良好的交流环境，请所有成员在发言前阅读并遵守本守则。

## 一、总则

1. 本守则适用于 KitterHub 全站的内容与互动，包括论坛帖子与评论、作品标题与描述、私信与群聊、工作室简介与公告、昵称与个性签名，以及上传的图片与语音。
2. 使用本站即视为已阅读并同意遵守本守则。
3. 发言前请考虑：屏幕另一端的成员与自己一样，正在学习与创作。请以希望被对待的方式对待他人。

## 二、鼓励的发言方式

1. 提问应完整：说明已尝试的做法、期望结果、实际结果与报错信息。
2. 回答宜说明理由，而非仅给出结论。
3. 欢迎分享创作过程，包括未完成的作品、失败的尝试与遇到的问题。
4. 对不确定的内容，建议如实说明，不宜给出未经核实的结论。
5. 称赞宜具体，例如指出某项实现的可取之处。

## 三、不得引战

「引战」指不以讨论问题为目的、而以引发争执为目的的发言。下列情形均属引战：

1. 以贬损性语言评价编程语言、工具、作品或其他成员；
2. 以年龄、性别、地区、技术水平等对他人作群体性评价；
3. 使用反语、阴阳怪气或故意激怒他人的表述；
4. 翻旧账、拉拢他人站队、召集他人进行争论；
5. 在他人作品下反复发表贬损性对比；
6. 传播未经证实、涉及他人品行或抄袭的传闻（如掌握证据，请通过举报提交）。

| 应避免的表述 | 建议改为 |
| --- | --- |
| 「XX 语言就是垃圾」 | 「XX 语言在该场景下的不足是……」 |
| 「用 XX 的都是小学生」 | 「XX 更适合哪些使用场景？」 |
| 「这也能叫作品？」 | 「若将此处改为……是否更合适？」 |
| 「不服来辩」 | 「我的理解可能不同，理由如下……」 |
| 「听说 XX 抄袭」 | 请通过举报提交证据 |

**遇到引战内容时**：请勿回应，亦请勿对骂，直接使用举报功能即可。

**参与对骂的双方均将依据本守则处理，不区分先后。**

## 四、发言规范

1. 标题应准确反映内容，避免「求助」「急」等无信息量的标题。
2. 同一问题请勿重复发布。
3. 请勿刷屏、连楼或发布无实质内容的回复。
4. 他人协助解决问题后，建议回复确认结果。
5. 指出问题时应针对内容本身，而非针对个人。
6. 使用 AI 生成或 AI 辅助的内容，请予以说明。

## 五、底线要求

1. **涉政内容**：立场正确、符合国家法律法规与社会主义核心价值观的内容，可正常发布；与之相抵触的内容不得发布，包括但不限于：否定中国共产党领导、否定国家主权与领土完整、歪曲历史、煽动民族与地域对立、攻击国家政策与国家领导人等。
2. 不得发布其他违反法律法规的内容。
3. 不得辱骂、歧视、人肉搜索或公开他人隐私信息。
4. 不得发布色情低俗、血腥暴力内容。
5. 不得发布广告、账号买卖、群组引流等信息。
6. 不得盗用他人作品、代码或素材；转载须注明出处。
7. 不得泄露本人或他人的真实姓名、学校、班级、住址、电话及照片。
8. **未成年成员请注意**：如遇他人索取照片、住址、钱财，或要求从事令你不适的行为，请勿答应，应及时举报并告知家长或老师。

## 六、审核与申诉

1. 命中敏感词的内容将自动进入待审，由管理员复核，不影响其他内容的正常发布。
2. 被举报的内容将进入审核队列。达到既定条件后，由风纪委员会（等级达到 LV3 可申请）判定；3 位委员均判「无违规」的，视为无违规。
3. 每次处理均会通知当事人，并说明所依据的条款。
4. 如认为处理有误，可发送邮件至 support@example.com，或通过站内「意见反馈」提交，并附账号与相关链接。申诉不影响处理结果的先行执行。

## 七、惩罚标准

依据违规的性质与影响，按下表处理：

| 档次 | 违规情形 | 处理标准 |
| --- | --- | --- |
| 一级 | 标题无信息量、重复发布同一问题、刷屏连楼、无实质内容的回复 | 提醒；反复出现的删除内容，不计违规 |
| 二级 | 轻度引战、阴阳怪气、针对个人的贬损、首次发布广告或引流、转载未注明出处 | 删除内容并警告，记违规一次 |
| 三级 | 反复引战、参与对骂、对他人作群体性贬低、恶意刷量或恶意举报、屡次发布广告 | 禁言 3 至 7 日，并扣除相应经验，记违规一次 |
| 四级 | 色情低俗、血腥暴力、侵犯隐私（人肉、开盒）、诈骗、账号买卖、外挂作弊、攻击本站 | 禁言 30 日或直接封禁 |
| 特别严重 | **涉政内容与国家法律法规、社会主义核心价值观相抵触**；其他违反法律法规的内容；涉及未成年人的色情或诱导；以任何形式索取钱财 | 永久封禁 |

**关于涉政内容**：立场正确、符合国家法律法规与社会主义核心价值观的讨论不受限制；与之相抵触的内容一经发现即**永久封禁**，不适用前述从轻情节与计次规则。情节严重的，本站将保存相关证据并依法向有关部门报告。

计次与从轻、从重：

1. 违规记录自处理之日起 90 日内有效；有效期内累计三次记违规的，按上一档处理。
2. 参与对骂的双方同等处理，不区分先后。
3. 主动删除违规内容、说明情况并致歉的，可从轻或免于处理；**涉政违规不适用本项**。
4. 组织、教唆他人违规，或使用多个账号规避处理的，从重处理。
5. 未成年成员的违规以提醒与教育为主，必要时限制相应功能。
6. 处理结果自通知送达时生效。对结果有异议的，可按第六条申诉。

## 八、附则

1. 本守则将根据社区发展情况修订，以本页最新版本为准。
2. 本守则未逐条列明、但明显妨碍社区正常交流的行为，管理员有权参照相近条款处理。
3. 对本守则有疑问或建议，欢迎通过「意见反馈」提出。
