# 第七篇 · 版权与侵权投诉指引

> 本篇是《KitterHub 社区管理规定》第七篇；规则总入口见站内「规则中心」。

本篇说明本站对著作权等权利的尊重与处理方式，以及权利人如何就站内侵权内容提出投诉。

## 一、权利归属

1. 用户在本站发布的作品、帖子与评论，其权利归发布者或原权利人所有；本站不因提供存储与展示服务而取得其著作权。
2. 本站的界面设计、程序代码、图形标识与自研素材，其权利归本站或相应权利人所有。
3. 用户使用的第三方编辑器（Kitten、NEMO、KN、Scratch 等）及其内置素材，权利归各自权利人所有，本站不对其作任何权利主张。

## 二、对用户的要求

1. 不得盗用他人作品、代码、素材、字体、音乐并声称原创。
2. 转载他人内容须注明原作者与出处；作者明确禁止转载的，不得转载。
3. 使用他人素材（含音乐、图片、音效）应确认已获得许可或属于允许使用的范围。
4. 二创作品应注明原作信息，并遵守原作的权利要求。

## 三、权利人如何投诉

权利人认为站内内容侵犯其合法权益的，可通过邮箱 support@example.com 提交书面通知，并包含以下材料：

1. **权利证明**：著作权登记证书、作品原始发布链接、创作过程记录等能够证明权利归属的材料；
2. **侵权定位**：涉嫌侵权内容的完整链接（或截图与账号标识），以及涉嫌侵权的具体说明；
3. **身份信息**：权利人的姓名或名称、联系方式（邮箱、电话）。若由代理人提出，需附授权文件；
4. **真实性声明**：声明所提供材料真实、合法，并愿意承担因通知不实而产生的法律责任。

## 四、我们的处理流程

1. **受理**：收到符合要求的通知后，我们将在 **3 个工作日**内确认受理并告知处理编号。
2. **核查与处置**：核查后如认定侵权成立，将采取删除内容、下架作品、限制功能等措施，并通知被投诉人。
3. **转通知**：我们会将通知的必要内容转送被投诉人，以便其作出说明或提出反通知。
4. **反通知**：被投诉人认为不构成侵权的，可提交反通知并附相应证据；我们会转送权利人，并视情况恢复内容。
5. **时限**：一般情形自受理之日起 **7 个工作日**内完成处置；情况复杂需延长的，会告知双方。
6. **争议解决**：本站的处置不构成对权利归属的最终判断。双方争议应通过协商或诉讼解决，本站将依法配合。

## 五、重复侵权

对多次被认定侵权、或经通知后仍继续侵权的账号，本站将采取警告、限制发布、禁言直至封禁的措施。

## 六、对用户的提示

1. 若你认为自己的作品被他人盗用，可先通过站内举报入口举报，或按本篇第三条提交正式投诉。
2. 若你被投诉，请勿在站内与对方争执（属引战，依第二篇处理），应按本篇第四条提交说明与证据。
3. 涉及音乐的特别提示：请勿上传从音乐平台下载的受版权保护的歌曲作为作品配乐；此类内容在收到权利人通知后将被直接下架。
