# 第五篇 · 未成年人保护规则

> 本篇是《KitterHub 社区管理规定》第五篇；规则总入口见站内「规则中心」。

本站以青少年创作者为主要用户群体，因此对未成年人的保护单列一篇，且执行标准高于一般条款。

## 一、基本立场

1. 未成年用户在本站享有与成年用户同等的创作与交流权利，同时受到更强的保护。
2. 涉及未成年人的侵害行为，本站**零容忍**，一经发现立即永久封禁，并依法保存证据、向有关部门报告。
3. 处理未成年用户的违规行为时，以提醒与教育为主，必要时限制相应功能；不因未成年人身份而免除对其发布违法内容的处理。

## 二、对未成年用户的要求

1. **不透露个人信息**：不得发布本人或他人的真实姓名、学校、班级、住址、电话、身份证件、清晰照片、其他平台账号、家庭情况等信息。
2. **不私下见面与转账**：不得与网友私下见面，不得向任何人转账、充值、代付，不得将账号密码告知他人。
3. **谨慎对待索要**：任何人以「帮忙、兼职、送礼物、带你上分」等理由索要照片、住址、钱财或验证码的，均为危险信号，应拒绝并举报。
4. **遇到不适立即求助**：如收到令你不适的私信、图片或要求，应立即停止对话、保留证据、举报，并告知家长或老师。

## 三、对全体用户的禁止事项

1. 不得以任何形式向未成年人索取照片、住址、钱财、验证码或账号密码。
2. 不得与未成年人谈论色情话题、发送色情或性暗示内容、提出线下见面要求。
3. 不得诱导未成年人充值、打赏、购买商品或参与任何形式的交易。
4. 不得以成年人身份冒充未成年人，或利用未成年人账号从事违规活动。
5. 不得发布针对未成年人的侮辱、歧视、威胁、恐吓内容。

**违反上述任一情形，直接永久封禁；涉嫌违法犯罪的，依法向有关部门报告。**

## 四、面向未成年人的内容限制

1. 不得发布任何涉及未成年人的色情、低俗、性暗示内容（包括文字、图片、语音、链接）。
2. 不得发布血腥暴力、自伤自残、危险行为示范等可能被模仿的内容。
3. 不得发布诱导消费、抽奖赌博、兼职刷单等针对未成年人的内容。

## 五、监护与配合

1. 未成年用户应在监护人指导下使用本站。发布涉及个人身份的信息前，应征得监护人同意。
2. 监护人如发现未成年人受到侵害，或认为本站不当收集了未成年人的信息，可通过站内「意见反馈」或邮箱 support@example.com 联系我们；我们会优先处理，并在必要时协助报警。
3. 我们会在未成年人相关举报中采取「先限制、后核查」的措施：对涉嫌侵害未成年人的内容与账号先行隐藏或限制，再行核实。

## 六、产品层面的保护措施

1. 站内不提供任何支付、打赏、充值功能。
2. 私信与群聊内容与其他站内内容适用同一套审核与举报机制；对涉及未成年人的举报设优先通道。
3. 「发布地」仅显示到省级归属地，不显示精确位置。

## 七、附则

1. 本篇未尽事项，依《社区发言守则》与相关分篇处理；与未成年人保护相关的部分，从严适用。
2. 举报与申诉渠道见第六篇《举报、申诉与处理规则》。
