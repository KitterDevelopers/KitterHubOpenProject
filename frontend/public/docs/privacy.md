# 第四篇 · 隐私政策

> 本篇是《KitterHub 社区管理规定》第四篇；规则总入口见站内「规则中心」。

本站尊重并保护用户个人信息。本政策说明我们收集哪些信息、如何使用与保护、以及你可以如何行使自己的权利。（第四篇与第三篇《用户协议》共同适用。）

## 一、我们收集哪些信息

1. **你主动提供的信息**
   - 账号信息：用户名、昵称、密码（以 bcrypt 加密存储，我们无法看到明文）、邮箱地址；
   - 绑定信息：编程猫账号的 UID 与昵称、GitHub 账号的 ID 与登录名（仅在你主动绑定时收集）；
   - 资料信息：头像、个人主页背景、个性签名、所在地区等你自行填写的资料；
   - 内容信息：你发布的作品、帖子、评论、私信、群聊消息、上传的图片与语音；
   - 验证信息：当你申请创作者身份或进行实名核验时提交的材料（如护照个人信息页等）。此类材料存放于**非公开目录**，仅管理员可查看。

2. **你使用服务时自动产生的信息**
   - 登录与操作记录：登录时间、IP 地址、IP 归属地（用于安全风控与展示「发布地」）、设备与浏览器类型；
   - 内容与互动记录：浏览、点赞、收藏、关注、举报等行为记录；
   - 必要的技术日志：用于排查故障与防范攻击。

3. **我们不收集**
   - 我们不会读取你的密码明文，不会收集你的通讯录、短信、相册或其他与本站功能无关的设备数据。

## 二、信息如何使用

1. 提供并维护服务：登录、发布内容、消息通知、经验等级与奖励结算。
2. 安全与风控：识别异常登录、批量注册、刷量、恶意举报与攻击行为。
3. 内容治理：敏感内容审核、举报处理、违规处置。
4. 改进服务：统计功能使用情况，优化体验。
5. 法律义务：依法配合有权机关的调查要求。

**我们不会将你的个人信息用于广告推送，也不会出售你的个人信息。**

## 三、Cookie 与本机存储

1. 本站使用浏览器「本机存储」保存登录令牌（用于保持登录状态），以及你的界面偏好设置（字体大小、主题色、背景图等）。这些数据保存在你自己的设备上。
2. 如果你在上传偏好中选择了背景图片，该图片保存在浏览器的本地数据库中，不会上传到服务器。
3. 清除浏览器数据会使你退出登录，并丢失本机偏好设置（已同步到服务器或作品内的数据不受影响）。

## 四、信息的共享与委托处理

1. **第三方登录**：使用编程猫或 GitHub 登录时，相应平台会按其隐私政策处理你的信息；我们仅接收用于建立绑定的必要标识信息。
2. **基础设施服务商**：本站部署于云服务器，使用对象存储、邮件与内容分发等服务，相关信息将按必要范围由相应服务商处理。
3. **法律要求**：根据法律法规、司法或行政机关的合法要求，我们可能提供必要信息。
4. 除上述情形外，我们不会向第三方提供你的个人信息。

## 五、信息的存储与保护

1. 数据存储于本站服务器（中国香港）及其备份中。
2. 我们采取的措施包括：密码加密存储、访问令牌校验与失效机制、敏感材料与非公开数据隔离存放、管理操作留痕（审计日志）、接口访问频率限制。
3. 请理解：互联网环境不存在绝对安全。请勿在站内发布本人或他人的敏感个人信息；如发现账号异常，请立即修改密码并联系我们。

## 六、保存期限

1. 账号信息在账号存续期间保存；账号注销后，我们将在合理期限内删除或匿名化处理，但法律法规要求保留的记录除外。
2. 违规处理记录与审计日志在必要期限内保存，用于处理申诉与配合监管。
3. 你删除的作品、帖子、评论等，将在合理时间内从公开页面移除。

## 七、你的权利

1. **查询与更正**：你可以在「账号设置」中查看并修改你的资料与绑定信息。
2. **删除**：你可以删除自己发布的内容；可以在「账号设置」中申请注销账号。
3. **撤回同意**：你可以解绑第三方账号、清除本机存储数据。
4. **投诉与咨询**：通过站内「意见反馈」或邮箱 support@example.com 联系我们。

## 八、未成年人信息

1. 本站用户中包含未成年人。我们仅在实现功能所必需的范围内收集其信息，不主动收集其真实姓名、学校、住址、联系方式等。
2. 未成年用户应在监护人指导下使用本站。监护人如认为我们不当收集了未成年人的信息，可联系我们要求删除。
3. 详见第五篇《未成年人保护规则》。

## 九、政策更新

本政策可能修订，修订后在本站「规则中心」公布并标注生效日期。继续使用本站即视为接受修订内容。
