# 第六篇 · 举报、申诉与处理规则

> 本篇是《KitterHub 社区管理规定》第六篇；规则总入口见站内「规则中心」。

本篇规定站内举报的提交方式、处理流程与时限，以及当事人对处理结果不满时的申诉渠道。

## 一、举报范围

对以下情形均可举报：

1. 违反《社区发言守则》第三至五条的内容（引战、辱骂、广告、色情低俗、暴力血腥、侵犯隐私、盗用素材等）；
2. 涉及未成年人的侵害行为；
3. 账号异常行为：批量注册、刷量、恶意举报、冒充他人、规避封禁；
4. 侵犯著作权等权利的内容（亦可按第七篇提出正式投诉）。

## 二、举报方式

1. **站内举报**：帖子、评论、作品、私信与群聊均有举报入口，选择类型并填写原因即可提交。
2. **意见反馈**：通过站内「意见反馈」提交，可附截图与链接。
3. **邮箱**：support@example.com（涉及未成年人或紧急情况建议直接使用邮箱并注明「紧急」）。

举报请尽量提供：内容链接、涉及账号、发生时间、具体情况说明与必要截图。

## 三、处理流程

1. **登记**：举报提交后进入审核队列。
   - 命中敏感词的内容会同时自动进入待审状态；
   - 同一内容被多名用户举报或达到既定条件时，进入风纪委员会审议。
2. **审议**：
   - 风纪委员会成员（等级达到 LV3 可申请）可对待审内容投票判定；3 位委员均判「无违规」的，视为无违规；
   - 委员可将明显违规内容先行隐藏，并送管理员复审。
3. **裁决**：由管理员依据《社区发言守则》第七条作出处理，并通知当事人与举报人。
4. **执行**：措施依次为提醒、删除内容、警告、禁言、封禁；严重违规与涉政违规直接封禁。

## 四、处理时限

1. 一般举报：自收到之日起 **3 个工作日**内处理完毕。
2. 涉及未成年人的举报：**优先处理**，一般于 24 小时内作出初步处置（先行限制、后核查）。
3. 涉及违法犯罪的紧急情形：立即处置，并依法向有关部门报告。
4. 需要当事人补充材料或情况复杂的，处理时限相应顺延，并告知举报人。

## 五、证据与举证

1. 我们以站内记录（内容、操作日志、IP 与时间等）为主要依据；站内记录已足以认定的，可不要求举报人另行举证。
2. 举报人应如实说明情况，不得伪造、篡改证据。
3. 被举报的当事人可以提供说明与反证，我们会一并考虑。

## 六、恶意举报

1. 下列行为属恶意举报：明知不违规而反复举报；以举报为手段骚扰、报复他人；组织多人集中举报同一正常内容；伪造证据举报。
2. 对恶意举报，视情节采取提醒、警告、禁言等处理；组织集中举报的从重处理。

## 七、申诉

1. **申诉渠道**：站内「意见反馈」，或邮箱 support@example.com。
2. **申诉材料**：账号标识、涉及内容链接、处理通知截图、申诉理由与必要证据。
3. **申诉时限**：建议在收到处理通知后 **15 日**内提出。
4. **处理时限**：我们一般在 **5 个工作日**内答复；复杂的可延长并告知。
5. **申诉不影响执行**：申诉期间原处理结果先行执行；申诉成立的，将撤销或变更原处理，并恢复相应内容与数据。
6. **终局性**：以下情形不接受申诉——涉政违规、涉及未成年人的侵害行为、攻击本站的行为。

## 八、风纪委员会

1. 组成：等级达到 LV3 的用户可申请，经管理员审核后在册履职。
2. 职责：参与待审内容的审议与投票；对明显违规内容先行隐藏并送审。
3. 约束：委员的判断同样受本篇约束；滥用职权、参与引战或违规的，将被停止履职，并按《社区发言守则》处理。
4. 委员的投票与处理记录公开留痕，接受监督。

## 九、附则

1. 本篇与《社区发言守则》配套适用；冲突时以《社区发言守则》的惩罚标准为准。
2. 本站保留对重大、紧急事项直接处置的权利。
