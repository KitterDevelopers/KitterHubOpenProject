> 本篇是《KitterHub 社区管理规定》第三篇；规则总入口见站内「规则中心」。

欢迎使用 KitterHub（以下称「本站」）。本协议是你与本站之间就使用本站服务所订立的约定。**注册或使用本站即表示你已阅读、理解并同意本协议全部条款。** 如果你不同意，请停止使用本站。

## 一、服务内容

1. 本站是一个面向创作者的社区，提供作品投稿与展示、论坛交流、工作室协作、即时通讯、经验等级与账号设置等功能。
2. 本站服务按「现状」提供，可能因维护、升级、故障、政策要求或不可抗力而中断、变更或终止部分功能。
3. 本站可以基于运营需要新增、调整或下线功能，重大变更会通过站内公告或通知告知。

## 二、账号

1. **注册**：你可以通过编程猫账号、邮箱或 GitHub 账号注册。你应提供真实、准确、完整的注册信息，并在信息变更时及时更新。
2. **账号归属**：账号仅供注册人本人使用。你应对账号下发生的一切行为负责，包括他人经你授权或未经授权使用你账号所产生的行为。
3. **保管义务**：请妥善保管账号与密码。勾选「在本机保存账号与密码」会将凭据明文保存在你自己的浏览器中，请勿在公用设备上使用该选项。
4. **禁止行为**：不得出租、出借、出售、赠与账号，不得批量注册账号，不得使用他人账号，不得以任何方式规避封禁或限制。
5. **密码找回**：绑定的邮箱是找回密码的唯一凭据。请绑定你本人长期可用的邮箱。
6. **注销**：你可以在「账号设置」中申请注销账号。注销后账号数据将按《隐私政策》处理，且**不可恢复**。

3. 你承诺：你发布的用户内容不侵犯任何第三方的著作权、商标权、专利权、肖像权、名誉权、隐私权等合法权益；你已取得必要授权；转载内容已注明出处。

5. 本站有权对违反法律法规或本协议、社区守则的内容进行处理，处理方式见《社区发言守则》第七条。

## 四、行为规范

1. 你应遵守《社区发言守则》，包括其中关于**引战、涉政内容、隐私保护与未成年人保护**的规定。
2. 你不得利用本站从事违法违规活动，不得攻击、扫描、爬取、干扰本站或他人的服务与数据，不得上传恶意代码。
3. 你不得利用技术手段刷取经验、小鱼干、点赞、关注等数据，不得恶意举报。

1. 本站用户中包含未成年人。未成年用户应在监护人指导下使用本站，并在发布涉及个人身份的信息前征得监护人同意。
2. 未成年用户不得发布本人或他人的真实姓名、学校、班级、住址、电话及照片。
3. 详见《未成年人保护规则》。
