# 账号设置

入口：「账号设置」，可通过个人头像菜单进入。

| 卡片 | 内容 |
| --- | --- |
| 账号概览 | 登录账号、昵称、邮箱、注册时间（只读） |
| 个人资料 | 头像、背景图、昵称、简介、性别 |
| 展示与隐私 | 背景图展示、等级徽章展示、性别公开；修改后立即生效 |
| 登录方式与绑定 | 邮箱、编程猫、GitHub 的绑定与解绑 |
| 密码 | 设置或修改本站密码 |
| 通知偏好 | 按类型订阅通知 |
| 账号安全 | 安全分与安全检查项 |
| 危险区 | 注销账号 |

## 头像与背景图

- 支持 JPG、PNG、WebP、GIF
- 背景图上传时可裁剪：拖动调整位置，滚轮或滑块缩放，按所选比例（默认 3:1）保存
- 已绑定编程猫时，可一键换回编程猫头像

## 邮箱

在「登录方式与绑定 → 邮箱」可绑定或换绑：先向新邮箱发送验证码，再填写验证码；若账号已设置本站密码，还需要输入当前密码。解绑后邮箱会变为占位地址，将无法使用邮箱找回密码。

## 密码

由编程猫账号自动创建的账号默认没有本站密码。设置后可以同时使用「账号密码登录」。修改密码后其他设备会自动下线。

## 通知偏好

按类型订阅通知，例如只接收提及而不接收点赞。

## 注销账号

注销后昵称、头像与全部内容将被隐藏，且无法再登录。此操作需要输入密码确认。
