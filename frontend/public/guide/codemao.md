# 编程猫账号：绑定与解绑

## 绑定

入口：「账号设置 → 登录方式与绑定 → 编程猫」。

- 填写编程猫账号（手机号或用户名）与密码
- 密码仅用于本次验证，不会保存在本站
- 绑定成功后昵称与头像会同步为编程猫账号信息

## 绑定后可用的功能

- 使用「编程猫登录」快捷登录
- 使用「免密验证」登录（不需要密码）
- 在投稿页导入自己的编程猫作品
- 在「经验中心」领取绑定奖励（+100 经验）
- 在「账号设置」一键换回编程猫头像

## 解绑

在「账号设置 → 登录方式与绑定 → 编程猫」可解绑。已领取的绑定奖励不会收回。

为避免账号无法登录，以下情况会被系统拦下：账号既没有可用的真实邮箱，也没有设置本站密码，同时没有绑定 GitHub。

## 注意事项

编程猫相关接口为非官方接口，编程猫改版时可能暂时不可用。遇到失败可稍后重试。
