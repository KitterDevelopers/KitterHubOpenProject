# 等级与经验

## 等级门槛

导航栏「经验中心」可查看当前等级、升级进度与完整等级说明表。

| 等级 | 升级条件 | 每日可领小鱼干 |
| --- | --- | --- |
| LV0 | 注册 | 0 |
| LV1 | 签订《友好条约》 | 1 |
| LV2 | 200 经验 | 1 |
| LV3 | 700 经验 | 2 |
| LV4 | 1500 经验 | 2 |
| LV5 | 5000 经验 | 3 |
| LV6 | 10000 经验 | 4 |
| LV7 | 50000 经验 | 5 |

## 等级解锁的功能

- **LV1**：评论、点赞、关注、发帖、投稿编程猫（编辑器）作品
- **LV4**：投稿内嵌网址作品、创建工作室
- LV5 及以上：创建的工作室成员上限提升

## 经验来源

| 来源 | 经验 | 说明 |
| --- | --- | --- |
| 每日签到 | +10 | 每天一次，在「经验中心」 |
| 投喂他人 | +10 / 个小鱼干 | 每天最多 +50 |
| 被投喂 | +1 / 个小鱼干 | 无上限 |
| 邀请好友 | +500 | 被邀请人注册成功后发放给邀请人 |
| 编程猫等级奖励 | 视编程猫等级 | 见下方 |
| 绑定奖励 | +100 / +20 / +50 | 见下方 |
| 其他奖励 | 管理员发放 | — |

投稿作品、发布帖子、被点赞**不再获得经验**。

## 绑定奖励

在「账号设置 → 登录方式与绑定」完成绑定后，可在「经验中心」各领取一次：

| 绑定项 | 经验 |
| --- | --- |
| 编程猫账号 | +100 |
| GitHub 账号 | +20 |
| 邮箱 | +50 |

解绑不会收回已领取的经验，每一项只能领取一次。系统自动生成的占位邮箱不算已绑定邮箱。

## 编程猫作者等级奖励

编程猫账号持有作者等级徽章（潜力新星及以上）时，可在「经验中心」领取对应奖励，编程猫 3、4、5 级可获得本站保底等级。该奖励为一次性记录；编程猫等级提升后可再次领取以补足差额，解绑编程猫账号不会收回。
