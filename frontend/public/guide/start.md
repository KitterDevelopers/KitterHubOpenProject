# 注册与登录

## 注册

- **中文界面**：目前仅支持编程猫账号注册。填写编程猫账号（手机号或用户名）与密码，系统会同步昵称与头像，并绑定该编程猫账号。
- **英文界面**：支持邮箱注册。填写用户名、邮箱、验证码与密码，验证码会发送到所填邮箱。

新注册账号等级为 LV0，仅可浏览内容。

## 登录方式

| 方式 | 说明 | 可用范围 |
| --- | --- | --- |
| 账号密码 | 用户名或邮箱 + 密码 | 全部 |
| 编程猫登录 | 已绑定编程猫账号可直接登录 | 全部 |
| 免密验证 | 用编程猫个人主页的一次性校验码登录，不需要密码 | 全部 |
| GitHub | 使用 GitHub 账号登录 | 仅英文界面 |

## 忘记密码

在登录页选择「忘记密码」，向绑定邮箱发送重置码，再填写重置码并设置新密码。

修改密码后，其他设备会自动下线，需要重新登录。

## 新账号建议先做的事

1. 签订《友好条约》升至 LV1（登录后会有提示）
2. 在「账号设置 → 登录方式与绑定」补绑邮箱与 GitHub（绑定有经验奖励，见侧栏「等级与经验」）
3. 需要投稿或发帖时，前往「创作中心」
