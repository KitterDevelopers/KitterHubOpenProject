# 工作室指南

## 创建

创建工作室需要 **LV4**。创建后自动生成专属讨论群与邀请码。

成员上限随创建者等级变化：LV4 为 30 人，LV5 为 50 人，LV6 为 80 人，LV7 为 120 人。

## 加入

- 开放加入：直接加入
- 审核加入：需要室长或管理员通过
- 凭邀请码加入

**每人最多同时加入 3 个工作室**（含待审核），退出后名额释放。部分工作室禁止多室籍，需要先退出其他工作室才能加入。

## 角色与权限

| 角色 | 权限 |
| --- | --- |
| 室长 | 编辑资料、成员管理、转让（需对方确认）、解散、置顶作品墙（最多 3 个） |
| 管理员 | 审核投稿、审核申请、禁言、移出成员、拉黑、全员禁言 |
| 成员 | 投稿、参与讨论群、申请成为管理员 |

## 作品墙

成员投稿需要审核，室长或管理员可直接上墙；室长可置顶最多 3 件作品。

## 注意

创建者不能退出自己的工作室，可以转让或解散。解散后所有数据会被删除，无法恢复。
