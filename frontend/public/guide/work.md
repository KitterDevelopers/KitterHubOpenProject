# 投稿稿件

## 投稿流程

投稿页按以下顺序填写：

1. **选择作品来源**：从编程猫导入 / 手动填写编号 / 内嵌网址
2. **稿件信息**：标题、简介、分类、标签、封面
3. **作品性质**：原创 / 转载（转载须标注原作地址）
4. **稿件设置**：发布方式与定时时间
5. **提交**

页面右侧固定显示预览、提交清单与提交按钮，清单会提示还差哪几项。

## 等级要求

- **LV1**：可投稿编程猫（编辑器）作品
- **LV4**：可投稿内嵌网址作品

## 发布方式

| 方式 | 说明 |
| --- | --- |
| 直接发布 | 立即上架 |
| 提交审核 | 进入管理员审核，通过后所有人可见 |
| 定时发布 | 到设定时间自动上架 |

内嵌网址作品一律需要管理员审核。

## 草稿

投稿页会自动保存草稿，可在「创作中心 → 我的草稿」继续编辑，也可另存为新草稿。作品发布后对应的草稿会清除。

## 其他

- 作品可加入作品合集，合成系列页展示
- 被驳回或下架的稿件可提交申诉，管理员会复核
- 稿件详情页支持点赞、收藏、投喂小鱼干与评论
